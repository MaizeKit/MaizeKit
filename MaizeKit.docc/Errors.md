# Errors

The messages visitors can see, and what they mean.

| Message | What it tells the visitor |
|---|---|
| **You’re not at the maze** | … away |
| **Turn on Precise Location** | Settings › Privacy & Security › Location Services › Safari Websites › Precise Location |
| **You’re not in the maze** | … away |
| **Can’t find a path near you** | Tap Fix my spot, then tap where you are |
| **Location is off** | Settings › Privacy › Location Services › Safari Websites. Or tap Fix my spot. |
| **Couldn’t load the maze** |  |
