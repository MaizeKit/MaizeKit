MaizeKit

Turn a photo of a corn maze map into a phone app that shows where you are and the way out.

Try a live maze Documentation GitHub

Why this exists

In October 2026 a friend got turned around in the corn maze at Moore Family Farm in Groton, New York. There was a map on a sign at the entrance, so we took a photo of it, lined it up with the field on satellite imagery, and built a page that shows your GPS position on the maze and draws the way out. She used it on her iPhone to walk to the exit.

MaizeKit is that page, cleaned up so any farm can make one.

What it does

  • Shows a blue dot for where you are, from the phone's GPS.
  • Draws the way to the exit along the real paths, from wherever you're standing, with the distance.
  • Lets you tap Fix my spot when GPS puts you a row off.
  • Holds the route steady instead of jumping between rows as GPS wobbles.
  • Keeps your location on your phone. There's no server and nothing is stored.
  • Prints an entrance sign with a QR code for the farm's own address.

Making one for your maze

  1. Make a copy of the MaizeKit template on GitHub.
  2. Add a straight-on photo of the maze map and describe it in maze.config.json.
  3. Run python tools/build_assets.py to find the paths and line the map up with the field.
  4. Turn on GitHub Pages and print the entrance sign.

The getting started guide walks through each step. It's free, and it runs as plain files on GitHub Pages.
