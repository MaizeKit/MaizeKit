# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/MaizeKit/MaizeKit/security/advisories/new),
not in a public issue.

MaizeKit is static files on GitHub Pages. It has no server and no accounts, and visitors'
locations stay on their phones. The main risks are in the page itself (for example, content
injected through a maze config) and in the publishing workflow.
